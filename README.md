# Frontend для сервиса управления ИБП

Лабораторная работа №5. Разработка базового SPA на React.

Базовое SPA-приложение на React + TypeScript (сборщик Vite). Интерфейс выполнен в виде мобильного приложения. На данном этапе (ЛР5) приложение работает только с mock-данными (без подключения к бэкенду и базе данных). В работе используются только `mock`-объекты.

## Стек технологий

- React (функциональные компоненты, хуки)
- TypeScript (строгая типизация)
- Vite (сборщик и dev-сервер)
- React Router DOM v6 (маршрутизация)
- React-Bootstrap (UI-компоненты)
- Чистый CSS
- Redux и React Context в данной работе **не используются**.

## Запуск проекта

1. Установите зависимости: `npm install`
2. Запустите сервер разработки: `npm run dev`
3. Откройте в браузере: `http://localhost:5173/` (или порт, указанный в консоли)

## Структура проекта

- `src/mock.ts` — массив мок-данных с услугами и динамическими атрибутами.
- `src/components/AppLayout.tsx` — общий лейаут с нижней панелью навигации и передачей данных через `Outlet`.
- `src/pages/FeedPage.tsx` — страница ленты.
- `src/pages/GridPage.tsx` — страница плитки с фильтром.
- `src/pages/DetailPage.tsx` — страница подробной информации с атрибутами.

## Описание страниц приложения (Поля и Кнопки)

Нижняя панель навигации содержит 4 пункта. На данном этапе работают только два из них: **«Лента»** и **«Плитка»**. Вкладки **«Добавление»** и **«Вход»** являются неактивными заглушками.

### 1. Страница «Лента» (маршрут `/`)
Вертикальный полноэкранный просмотр (формат Reels/TikTok).
- **Элементы отображения:** Видео (или картинка) на фоне, Название ИБП, Текст описания, Параметры (Ёмкость, Максимальный ток).
- **Поля:** Отсутствуют поля ввода.
- **Кнопки:**
  - **Ещё / Свернуть** — текстовая кнопка для показа полного описания.
  - **Сердечко (Лайк)** — кнопка-иконка для постановки лайка.
  - **Далее** — кнопка-иконка для перехода к следующей карточке.

### 2. Страница «Плитка» (маршрут `/grid`)
Сетка карточек в 2 колонки.
- **Элементы отображения:** Карточки с изображениями, названием, ёмкостью и счетчиком лайков.
- **Поля:**
  - `Input` (числовое поле) — для ввода минимальной ёмкости (фильтрация на клиенте).
- **Кнопки:**
  - **Поиск** — кнопка с иконкой лупы для применения фильтрации.
  - **Клик по карточке** — вся карточка является кликабельной ссылкой (переход на страницу «Подробнее»).

### 3. Страница «Подробнее» (маршрут `/detail/:id`)
- **Элементы отображения:** Изображение услуги, полное название, описание, и **список динамических атрибутов** (характеристики).
- **Поля:** Отсутствуют.
- **Кнопки:** Отсутствуют (только навигация через нижнее меню или кнопку "Назад" в браузере).

## Медиафайлы и заглушки

Все изображения хранятся локально в папке `public/`. Если в mock-данных поле `image_url` пустое (или файл не загрузился), срабатывает защита (fallback): вместо отсутствующей картинки выводится локальная заглушка `/default.png`.
